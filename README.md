# Advanced Modern Calculator

A premium, responsive calculator web app built with HTML5, CSS3, and Vanilla JavaScript.

## Features
- Basic operations: +, −, ×, ÷, %, decimal, +/−, AC, DEL, =
- Safe expression parser (no eval)
- Operator precedence, continuous calculations
- Division by zero handling, decimal precision
- Keyboard support
- Calculation history with localStorage persistence
- Light/dark theme toggle
- Copy result, sound effects (toggleable)
- Responsive mobile-first design

## Run
Open `index.html` in any modern browser. No build step required.

Optionally serve locally:
```
npx serve .
```
